A primeira versão do código implementa um sistema bancário simples diretamente dentro do while, utilizando estruturas condicionais (if, elif) para realizar depósitos,
saques e exibir o extrato. O programa controla saldo, limite de saque e quantidade máxima de saques, armazenando todas as operações em uma variável de texto para mostrar no extrato.

A segunda versão apresenta uma melhoria na organização do código, separando as funcionalidades em funções como depositar(), sacar() e extrato().
Isso deixa o programa mais modular, reutilizável e fácil de manter, além de aproximar o projeto de uma estrutura mais profissional.
Também foram utilizados conceitos importantes do Python, como funções e variáveis globais (global).
